# security

## reporting a vulnerability

email <contact@joeltaylor.business>. please do not open a public issue for a
vulnerability, and do not post one in a pull request or a discussion.

include what you found, how to reproduce it, and what an attacker gets. a proof
of concept helps but is not required.

you will get an acknowledgement within a few days. once a fix is out, you are
welcome to write about it, and you will be credited unless you prefer not to be.

## scope

the collector, the database schema and the contract packages in this repository.
mercadona's own services are not in scope: this project is unaffiliated with
them, and anything found there belongs to mercadona.
